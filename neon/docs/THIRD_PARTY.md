Shell Arena WAV files are generated by the included Python synthesizer. No
audio from GunZ, Watch Dogs or Cyberpunk is copied. The optional macOS player
uses `afplay`; Linux/WSL uses `paplay` with the existing audio server.

From the dev-env root you can regenerate the sound packs with:

```bash
python3 neon/vendor/shell-arena/arena_audio.py generate neon/vendor/shell-arena/sounds
```

Arena's historical standalone installer and README remain under its vendor
directory for reference. For this integration use **`neon-install.py`** from
the dev-env root so there is a single managed installation and backup record.
